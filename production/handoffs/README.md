# Handoffs

One file per finished task, `<task-id>.md`, written by the task's owner when it moves to
`Review`. QA reads it first.

```
# <task-id> <title>

## Done
What was built, and how it was seen running (snapshot, showcase, two-instance launch).

## Files changed

## For the next role
What a dependent task or reviewer needs to know: new names, contract changes, how to test.

## Open
Anything left, guessed or only a group playtest can settle.
```
